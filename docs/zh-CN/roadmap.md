# 公开产品路线图

[English](../roadmap.md)

CtxTTL Core 是公开工程主线，并保持对特定 Agent 运行时、模型供应商和 Benchmark 的独立性。

## 近期方向

- 完善共享部署下的鉴权与授权指引；
- 保持存储、检索、Token 估算、模型供应商和运行时接入可独立替换；
- 扩展通用 HTTP 与 MCP 契约测试；
- 改进迁移、可观测性、打包和部署文档；
- 通过文档清单增量增加语言包。

## 仓库边界

本仓库只发布产品代码、确定性 Fixture 和契约测试。凭据、私有运行数据、供应商载荷与非产品
工作始终保留在 Git 之外。
