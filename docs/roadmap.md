# Public product roadmap

[简体中文](zh-CN/roadmap.md)

CtxTTL Core is the public engineering line. It remains independent of any particular Agent
runtime, model provider, or benchmark.

## Near term

- harden authentication and authorization guidance for shared deployments;
- keep storage, retrieval, tokenization, providers, and runtime integrations replaceable;
- expand the universal HTTP and MCP contract suites;
- improve migrations, observability, packaging, and deployment documentation; and
- add language packs through the documentation manifest.

## Repository boundary

This repository publishes product code, deterministic fixtures, and contract tests. Credentials,
private runtime data, provider payloads, and non-product work remain outside Git.
